Py Inspector is a lightweight desktop code editor, entity/script launcher, and live syntax error scanner built with Python and Tkinter. Styled after classic Source/Hammer Editor dark interfaces, it helps inspect Python scripts and JSON files, run scripts or JSON payloads directly through Python, and execute shell commands from a built-in console panel.   

Key Features
Live & Manual Error Scanner: Continuously checks Python syntax (compile and ast) and JSON validity, while flagging mixed tabs/spaces, trailing whitespace, and bare except: blocks.   

JSON-to-Python Runner: Executes JSON files or editor contents via Python—running embedded code, script, python, or py fields if present, or generating a runner script that prints parsed JSON data.   

Entities / Scripts Launcher: Keeps a persistent manifest (entities_manifest.json) of .py, .json, .exe, .bat, and .cmd entries for quick launching with a single click or double-click.   

Built-In CMD Console: Runs shell commands directly in the configured save directory and supports quick built-in commands like scan, check, clear, and runjson.   


Configurable Workspace & File Tools: Supports creating, opening, saving, and saving-as files (.py, .json, .txt, .vmf, .cfg), choosing a custom save folder, and opening it in the file explorer.
